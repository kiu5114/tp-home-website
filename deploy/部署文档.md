# TP 全屋家居 · 部署文档

> 阶段 4 产物（部署骨架）。覆盖：本地开发启动、Docker 部署、Nginx 网关、生产注意事项。

## 1. 技术栈与端口约定

| 组件 | 技术 | 本地端口 | 容器端口 |
|---|---|---|---|
| 前端前台（web） | React + Tailwind + Vite | 5173 | 由 Nginx 托管 `/` |
| 前端后台（admin） | React + AntD5 + Vite | 5174 | 由 Nginx 托管 `/admin/` |
| 后端 API | FastAPI + SQLAlchemy | 8000 | 8000（仅容器内） |
| 网关 | Nginx | — | 8080（对外） |

## 2. 本地开发启动

### 2.1 后端
```bash
cd backend
# 首次：创建虚拟环境并安装依赖（Windows Git Bash）
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt

# 启动（lifespan 自动建表 + 幂等 seed）
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```
- 接口文档：http://127.0.0.1:8000/docs
- 默认账号：`admin / admin123`（**上线前必须修改**）

### 2.2 前端
```bash
# 项目根目录
npm install
npm run dev:web     # http://127.0.0.1:5173
npm run dev:admin   # http://127.0.0.1:5174
```
- 前端通过 `VITE_API_BASE` 指向后端（默认 `http://127.0.0.1:8000`）。
- 可在 `apps/web/.env`、`apps/admin/.env` 中覆盖。

## 3. Docker 部署（一键）

前置：本机已装 Docker，前端已构建：
```bash
npm run build:web
npm run build:admin
```

启动：
```bash
docker compose -f deploy/docker-compose.yml up -d --build
```
- 访问：前台 http://localhost:8080、后台 http://localhost:8080/admin/
- 停止：`docker compose -f deploy/docker-compose.yml down`
- 数据卷：`tp_uploads`（上传文件）、`tp_db`（SQLite），重建容器不丢数据。

## 4. Nginx 网关说明（deploy/nginx.conf）

- `/` → 前台静态包（SPA History 回退到 index.html）
- `/admin/` → 后台静态包（回退到 /admin/index.html）
- `/api/` → 反向代理到后端 8000
- `/uploads/` → 反向代理到后端静态目录

> 若前后端分域名部署，需把 `/api/`、`/uploads/` 的 `proxy_pass` 改为实际后端地址（如 `http://backend-server:8000`），并将 web/admin 的 `VITE_API_BASE` 构建为完整后端域名。

## 5. 生产注意事项

1. **改默认密码**：登录后立刻修改 `admin` 密码；或修改 `seed.py` 中初始密码后重新 seed。
2. **数据库（SQLite → PostgreSQL）**：当前为 SQLite（单文件，适合中小规模）。数据库设计文档已按"双形态"建模（SQLite↔PostgreSQL 兼容，JSON 列自动映射 SQLite TEXT / PostgreSQL JSONB），切换步骤：
   - **驱动已就绪**：`requirements.txt` 已含 `psycopg[binary]`；
   - **连接串**：设置环境变量 `DATABASE_URL=postgresql+psycopg://user:pass@host:5432/dbname`（`database.py` 自动读取）；
   - **建表迁移已就绪**：`backend/alembic/versions/` 已生成完整 init 迁移（20 表，已在空库实测 `upgrade head` 通过）。执行：
     ```bash
     cd backend
     DATABASE_URL="postgresql+psycopg://user:pass@host:5432/dbname" alembic upgrade head
     ```
   - **Docker 一键方案**：`deploy/docker-compose.yml` 内含注释掉的 `postgres` 服务，取消注释并把 `api.environment.DATABASE_URL` 切为 PG 连接串即可；启动后跑 `docker compose -f deploy/docker-compose.yml run --rm api alembic upgrade head`；
   - **数据迁移**：从 SQLite 迁到 PG 属业务数据迁移，可用 `pgloader` 或导出/导入 SQL（本项目 SQLite 仅开发用，生产直接建表 + seed 即可）。
3. **上传目录**：生产环境务必把 `/uploads` 挂载到持久化磁盘（Docker 已用数据卷）。
4. **HTTPS**：网关前建议加 TLS（Nginx 443 + 证书），并把 `allow_origins` 改为正式域名。
5. **备份**：定期备份数据库与 uploads 目录（操作日志已内置，可配合定时任务导出）。
6. **admin 体积优化（已完成）**：admin 已按路由 `React.lazy` 分包 + ECharts 按需引入 + `manualChunks` 拆分 vendor（react/antd/echarts），主包由 2.3MB 降至约 65KB（业务）+ 三方库独立长缓存 chunk。
